Multimodal Explainable AI for Heart Disease Risk Prediction

Project Overview
This project predicts the risk of heart disease using machine learning and explainable AI techniques.  
It integrates multiple datasets containing clinical, demographic, and lifestyle data to improve prediction accuracy.

The system also provides explanations for predictions using SHAP and LIME so that the model results are transparent and interpretable.


Features
- Heart disease risk prediction using machine learning
- Integration of multiple datasets
- Model comparison between different algorithms
- Explainable AI using SHAP and LIME
- Interactive web application using Streamlit


Machine Learning Models Used
- XGBoost
- Random Forest
- Gradient Boosting

Evaluation metrics used:
- Accuracy
- Precision
- Recall
- F1 Score


Datasets
The project uses multiple datasets including:
- Heart Disease Dataset
- Framingham Heart Study Dataset

These datasets contain clinical measurements, demographic information, and lifestyle factors.


Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- LIME
- Matplotlib
- Seaborn
- Streamlit


How to Run the Project

1. Clone the repository
git clone https://github.com/KSudhaSamhitha/HealthMajorProject.git

2. Navigate to the project folder
cd HealthMajorProject

3. Install dependencies
pip install -r requirements.txt

4. Run the application
streamlit run app.py


Outcome
The system predicts heart disease risk and provides explainable insights that help understand which factors contribute to the prediction.
